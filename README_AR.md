# PURPLE CRYSTAL — لعبة مراجعة Python (Lecture 3)

## محتويات المشروع
- `index.html` — صفحة اللعبة.
- `style.css` — التصميم وثيم الموف الكريستالي.
- `script.js` — بنك الأسئلة، النقاط، والتصحيح.

اللعبة تحتوي على 60 سؤالًا: 45 اختيارًا من متعدد و15 سؤالًا قصيرًا/مقاليًا. تغطي المقارنات، العوامل المنطقية، وتتبع تنفيذ شروط `if/else` في Python، بثلاثة مستويات صعوبة.

## تشغيل اللعبة على جهازك
1. فك ضغط الملف ZIP.
2. افتح `index.html` بالنقر عليه مرتين.
3. ستعمل اللعبة في المتصفح، ولا تحتاج إلى Python أو إنترنت للتشغيل المحلي.

## رفعها مجانًا على GitHub Pages
1. سجّل الدخول إلى https://github.com/ وأنشئ مستودعًا جديدًا (New repository)، مثل `purple-crystal-quiz`.
2. اجعل المستودع **Public**، ثم اضغط **Create repository**.
3. من صفحة المستودع اضغط **Add file → Upload files**.
4. افتح ملف ZIP على جهازك أولًا، ثم ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` مباشرةً إلى جذر المستودع (لا ترفع مجلدًا يحتوي عليها فقط).
5. اضغط **Commit changes**.
6. افتح **Settings → Pages**.
7. تحت **Build and deployment** اختر **Deploy from a branch**.
8. اختر الفرع `main` والمجلد `/(root)`، ثم اضغط **Save**.
9. انتظر قليلًا وافتح صفحة **Settings → Pages** مرة أخرى؛ سيظهر رابط الموقع المنشور. افتح الرابط وجرب اللعبة.

## ملاحظات
- لا تحتاج اللعبة إلى خادم أو قاعدة بيانات، ولا ترسل الإجابات إلى أي مكان.
- النقاط موجودة خلال جلسة اللعب الحالية ولا توجد لوحة متصدرين مشتركة.
- تصحيح الأسئلة المقالية تقريبي باستخدام كلمات مفتاحية؛ راجع الإجابة النموذجية والتفسير الظاهرين عند الحاجة.
