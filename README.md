# PURPLE CRYSTAL — Conditional Execution Quiz

A static browser quiz converted from the Lecture 3 Python conditional-execution quiz. Includes 60 questions (45 multiple-choice and 15 short-answer/essay), three difficulty levels, points, instant multiple-choice feedback, approximate keyword grading for written answers, and a shiny purple-crystal theme.

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No Python or internet connection is required for local play.

## Free GitHub Pages hosting
1. Create a **Public** repository on https://github.com/.
2. Choose **Add file → Upload files**.
3. Extract this ZIP, then upload `index.html`, `style.css`, and `script.js` directly to the repository root.
4. Commit the files.
5. Go to **Settings → Pages**.
6. Choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
7. After deployment, open the URL shown on the Pages settings screen.

Written-answer scoring is approximate keyword matching. Scores are session-only; there is no backend or shared leaderboard.
